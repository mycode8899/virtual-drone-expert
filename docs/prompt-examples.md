# 提示词示例库

专家理解自然语言，不需要固定语法。推荐结构：

```
[风格] + [机位：高度 / 距离 / 方位] + [运动节奏] + [时长] + [画质约束]
```

不必写全，但**风格 + 至少一个机位维度**能显著提升稳定性。以下示例可直接复制使用。

---

## 1. 最小可用

> 把这段视频改成虚拟无人机后方跟拍。

## 2. GTA6 电影感（完整参数）

> 把这段视频改成 GTA6 风格的空中跟拍：机位在主体后方 8 米、高 4 米，缓慢加速跟随，50mm 压缩感，最后 2 秒平滑拉升到俯瞰。输出 6 秒，保持主体外观和衣服颜色一致，加自然运动模糊和黄昏侧逆光。

## 3. Reality View 式俯视跟随

> 用特斯拉 Reality View 那种车身上方偏后的虚拟相机视角重拍这段行车视频，俯角约 45°，全程匀速跟随，路面与两侧建筑保持连贯，不要出现镜头翻转。

## 4. FPV 高速穿越

> 低空 2 米、距离主体 4 米，FPV 高速跟拍，广角 16mm，快速穿越时加运动模糊；主体轮廓要稳，背景可以糊。4 秒就好。

## 5. 缓慢环绕

> 主体基本不动，虚拟无人机以 6 米半径、10 秒一圈匀速环绕，高度 3.5 米，光线保持一致，适合做产品展示。

## 6. 拉升转场

> 前 3 秒贴身跟拍，后 3 秒一镜拉升到 20 米高空俯瞰整条街，中间不要切镜，保持同一主体。

## 7. 宠物 / 动物

> 这段狗在草地上跑，改成侧后方 45°、高 3 米的跟拍，距离 6 米，速度跟它一致，草地纹理别闪，保留毛色与项圈。

## 8. 先出方案再生成

> 先别生成。分析一下这段视频的主体、运动方向和环境，给我 3 套虚拟无人机机位方案（各自的高度、距离、方位、预期效果），我选一套再出片。

## 9. 迭代修图

> 上一版主体在转弯时变形了。保持同样的机位和风格重出一次，但把时长缩到 4 秒、降低镜头加速度，并明确「主体外观全程不变」。

## 10. 只做镜头设计（无视频生成能力时）

> 当前环境不能生成视频，请只输出镜头设计方案：分镜表（时间 / 机位 / 运动 / 画面内容）加一段可直接喂给视频模型的英文提示词。

## 参数速查

| 维度 | 常用表达 |
| --- | --- |
| 高度 | 贴地 2–3 m / 跟拍 4–8 m / 俯瞰 15 m+ |
| 距离 | 近 4–6 m / 标准 8–10 m / 远 15 m+ |
| 方位 | 正后方 / 侧后 45° / 正上方偏后 / 前方倒退 |
| 速度 | 匀速 / 缓慢加速 / 急推 / 急停 / 一镜拉升 |
| 焦段感 | 16–24mm 广角 / 50–85mm 压缩 |
| 时长 | 4–8 秒（越长越容易漂移） |
| 画质 | 主体一致 / 自然运动模糊 / 光影连贯 / 无镜头翻转 / 无背景闪烁 |

## 提高成功率的小技巧

- **主体单一**比多人多车更稳；主体占比太小容易丢。
- **原视频镜头越稳越好**；手持剧烈抖动的素材先说明「忽略原镜头抖动」。
- **一次只改一个变量**，否则难以判断哪项调整有效。
- 明确写出**要保持不变的东西**（衣服颜色、车型、项圈、光照方向）。
- 长镜头拆成两个短片段再拼接，通常比硬出 10 秒更干净。
