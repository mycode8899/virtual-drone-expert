# 常见问题

### Q1. 这个仓库里有模型吗？能直接跑出视频吗？

没有。仓库里只有 Agent 提示词、元数据、头像和文档。视频生成由宿主平台（WorkBuddy / CodeBuddy）接入的视频模型完成。如果当前会话没有视频生成能力，专家会退化为「镜头设计 + 可复制的生成提示词」，不会凭空产出文件。

### Q2. 这是 Tesla Reality View / GTA6 的官方实现吗？

不是，也没有任何关联或授权。`GTA6`、`Tesla`、`Reality View` 仅作为**视觉风格的指代**。本专家借用「虚拟无人机跟拍」这一镜头范式，输入是单条离线视频，与车端多摄像头实时生成是完全不同的问题。

### Q3. 为什么成片里背景会变形、闪烁，主体偶尔「换脸」？

因为单条视频缺少多视角几何约束。被遮挡的背面、路面细节、远处建筑都要靠模型先验补全。改善方向：缩短时长（4–6 秒）、降低镜头加速度、让主体在画面中占比更大、明确写出要保持的外观特征、避免快速横摇。

### Q4. 支持哪些视频格式和时长？

取决于宿主平台。实践建议：3–15 秒、≥720p、常见 mp4/mov、主体清晰、原镜头运动平缓。超长素材建议先剪成短片段再处理。

### Q5. 一次能生成多久？为什么建议 4–8 秒？

同样取决于平台上限。即便支持更长，生成式视频在 8 秒后主体漂移、纹理闪烁的概率明显上升；分两段生成再拼接通常更干净。

### Q6. 能把生成结果用在事故还原、监控取证或测距吗？

**不能。** 画面中的几何、遮挡与细节是 AI 补全的，不具备事实准确性。请勿用于证据、工程测量、安全评估或任何需要真实空间关系的场景。

### Q7. 上传别人的视频 / 含人脸的素材，有风险吗？

有。请只使用你拥有权利或已获授权的视频，并在公开发布前确认肖像权、著作权与平台规则。仓库的 `.gitignore` 已排除视频与成片，请不要把素材提交进来。

### Q8. 导入后专家列表里看不到，怎么办？

多半是 zip 结构问题：顶层应为 `virtual-drone-expert/`，且 `.codebuddy-plugin/plugin.json` 在该目录内。用 `python scripts/build-package.py` 重新打包，或按 [安装文档](./installation.md) 的目录结构手工放置。

### Q9. `GAT6` 和 `GTA6` 哪个对？

`GTA6`（Grand Theft Auto VI）。原始包中的 `GAT6` 是笔误，v1.0.0 已统一修正。搜索旧资料时可用 `GAT6` 作为关键词找到历史版本。

### Q10. 为什么删掉了原理说明里的某个人名？

原提示词把 Reality View 的技术解析归给某位个人，但在可检索的公开资料中无法核实该归因。v1.0.0 起改为「公开报道与社区解读」，并在 [技术原理](./principles.md) 中列出可核查的链接。如果你有确凿的一手出处，欢迎提 PR 补回。

### Q11. 怎么改专家的名字、头像、快捷提示词？

改 `.codebuddy-plugin/plugin.json` 的 `displayName` / `quickPrompts`，以及 `avatars/expert.png`（保持文件名）。`name`、`agentName`、`agents` 是导入契约，不要动。详见 [安装文档](./installation.md)。

### Q12. 想加英文版提示词怎么做？

翻译 `agents/virtual-drone-expert.md`，在 `plugin.json` 的 `agents` 数组里增加路径，或在提示词内加一条「按用户语言切换」规则。欢迎直接提 PR。
