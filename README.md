## 一句话说明

这是一个**专家包**，不是一段可独立运行的推理程序。它把「视频 → 虚拟空中跟拍视角」这件事拆成一套明确的工作流（分析主体 → 设计相机路径 → 生成新视角 → 给出调参建议），写成 Agent 提示词，交给宿主平台执行。

```
你的视频  ──►  场景 / 主体 / 运动分析  ──►  虚拟无人机相机路径设计  ──►  新视角视频
              （理解）                    （镜头语言）              （平台视频生成能力）
```

📦 **仓库里有什么**：一份中文 Agent 提示词、一份 `plugin.json` 元数据、一个头像资源，以及配套文档与打包脚本。
🚫 **仓库里没有什么**：模型权重、推理服务、训练代码、任何第三方 API 调用。**实际生成视频的能力由 WorkBuddy / CodeBuddy 所接入的视频生成模型提供。**

> ⚠️ **效果预期**：从**单条普通视频**合成物理一致的新视角，目前仍是开放的研究问题。本专家产出的是**风格化重演**——主体、运动趋势、色调与光影会尽量保留，但几何关系、遮挡和背景细节属于生成式补全，不等于精确的三维重建，也不等于特斯拉车端那套多摄像头实时系统。

## 能做什么

| 风格 | 典型画面 | 适合素材 |
| --- | --- | --- |
| **GTA6 电影感** | 第三人称高位跟拍、开放世界式饱和光影、宽幅运动镜头 | 街道、跑酷、行车、人群 |
| **Reality View 式** | 主体正上方偏后的虚拟相机、俯视跟随、路径感强 | 行车、骑行、轮滑 |
| **FPV 高速** | 低空贴地、快速穿越、强运动模糊 | 运动、赛车、宠物奔跑 |
| **缓慢环绕** | 主体基本不动、镜头匀速绕行 | 人物、产品、静态主体 |
| **拉升转场** | 从近距跟拍平滑拉升到高空俯瞰 | 旅行、城市、活动记录 |

**输入**：任意视频（人、车、动物、街景等）。
**输出**：新的虚拟空中跟拍视频 + 可继续微调的参数建议。

## 快速开始

1. 从 [Releases](../../releases) 下载 `virtual-drone-expert.zip`；或在仓库根目录执行 `python scripts/build-package.py` 自行打包。
2. 打开 WorkBuddy → **专家** → 导入本地专家包，选择该 zip（也可直接将本仓库目录放入本地专家目录）。
3. 与「虚拟无人机拍摄专家」对话并上传视频。
4. 描述你想要的镜头，例如：

   > 把这段视频改成 GTA6 风格的空中跟拍：机位在主体后方 8 米、高 4 米，缓慢加速跟随，最后 2 秒拉升到俯瞰。

完整步骤见 [安装与使用](./docs/installation.md)，更多写法见 [提示词示例](./docs/prompt-examples.md)。

## 可调参数

专家会理解自然语言，不必记参数名；但把这几个维度说清楚，成片稳定性会明显提升。

| 维度 | 含义 | 常用取值 |
| --- | --- | --- |
| `高度` | 虚拟相机离地高度 | 2–3 m（贴地 FPV）/ 4–8 m（跟拍）/ 15 m+（俯瞰） |
| `距离` | 相机与主体的水平间距 | 5–15 m |
| `方位` | 相对主体的机位 | 正后方 / 侧后 45° / 正上方偏后 / 前方倒退 |
| `速度` | 跟随与镜头运动节奏 | 匀速 / 缓慢加速 / 急推 / 急停 |
| `焦段感` | 广角到长焦的视觉压缩 | 16–24 mm 广角（沉浸）/ 50–85 mm（压缩、电影感） |
| `时长` | 输出片段长度 | 建议 4–8 s，过长易出现主体漂移 |
| `风格` | 上面 5 种预设之一 | 可组合，如「FPV + GTA6 调色」 |

## 技术背景（30 秒版）

2026 年 11 月，特斯拉 FSD v15 推送了 **Reality View**：不用游戏引擎、不用摄像头拼接，而是由车端生成模型从多路摄像头的视觉特征里，实时「画」出车辆上方虚拟相机视角的画面，观感被大量车主和媒体形容为「像 GTA6」。公开报道提到的关键数字包括：约 10 亿参数的生成支路、共享的视觉编码器（UVE）、每次生成 8 帧 / 36 fps、约 220 ms 时延、AI4 上约半个 TRIP 的算力。

本专家**借用这一视觉语言与工作流作为创作范式**，并不复刻其技术实现：输入从「多摄像头实时流」变成了「单条离线视频」，输出结果因此是艺术化重构而非感知结果的可视化。

完整说明、口径差异与参考链接见 [docs/principles.md](./docs/principles.md)。

## 局限与合规

- **不是技术复刻**。不声称使用、包含或复现特斯拉的模型、代码或数据。
- **商标**。`GTA6` / `Grand Theft Auto`、`Tesla`、`Reality View` 均为各自权利人的商标或产品名称，此处仅作**视觉风格的指代性描述**，本项目与之无任何关联、授权或背书关系。
- **素材版权**。请只上传你拥有权利或已获授权的视频；生成结果用于公开传播前，自行确认肖像权、著作权与平台规则。
- **事实性用途**。生成画面是 AI 补全的结果，**不可**用于事故还原、证据留存、测距或任何需要几何准确性的场景。
- **效果依赖宿主能力**。不同平台的视频模型在主体一致性、时长上限、分辨率上差异很大，详见 [FAQ](./docs/faq.md)。
